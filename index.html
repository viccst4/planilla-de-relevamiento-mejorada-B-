1. Introducción al Relevamiento

¿Qué es un relevamiento de hardware?

Es un proceso técnico que permite identificar, registrar y analizar los componentes físicos de una computadora o de un conjunto de equipos informáticos.

Objetivo

El objetivo principal es conocer el estado actual de los equipos, detectar fallas, planificar mantenimientos, evaluar posibles actualizaciones y organizar mejor los recursos tecnológicos disponibles.

2. Componentes a Relevar

  • Hardware crítico: procesador, memoria RAM, disco rígido o SSD y placa madre.
  • Hardware complementario: placa de video, fuente de alimentación y sistema de refrigeración.
  • Hardware adicional: monitor, teclado, mouse, impresora, parlantes y dispositivos de red.

3. Pasos para realizar el Relevamiento

  1. Identificar el equipo, el sector donde se encuentra y el responsable de la carga.
  2. Registrar los datos técnicos principales del equipo.
  3. Observar el estado general y anotar fallas o problemas detectados.
  4. Definir si requiere mantenimiento, reparación, actualización o reemplazo.
  5. Guardar la información para futuras consultas o toma de decisiones.
